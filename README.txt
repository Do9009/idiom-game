사자성어 퀴즈 웹 앱

파일:
- index.html: 웹 앱 본체
- manifest.webmanifest: 홈 화면 설치 설정
- sw.js: 오프라인 캐시
- icon.svg: 기본 앱 아이콘

사용:
1. 이 폴더를 정적 웹 호스팅(Vercel, Netlify 등)에 업로드합니다.
2. 발급된 HTTPS 주소를 PC 또는 스마트폰에서 엽니다.
3. iPhone: Safari 공유 메뉴 > 홈 화면에 추가
4. Android: Chrome 메뉴 > 앱 설치 또는 홈 화면에 추가

주의:
- 현재 버전은 브라우저 안에서 실행되는 정적 웹 앱입니다.
- 점수/퀴즈 진행은 서버 없이 기기 안에서 처리됩니다.
- 현재 아이콘은 임시 SVG입니다. 기존 icon.png를 웹용 PNG로 추가 교체할 수 있습니다.
